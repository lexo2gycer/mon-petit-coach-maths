# Mon petit coach de maths

Première version d'une petite application de révision pour téléphone.

## Fonctionnalités
- Écran d'accueil avec missions Addition et Soustraction.
- Exercices générés automatiquement.
- Saisie des résultats chiffre par chiffre.
- Cases pour les retenues (addition) et les emprunts (soustraction).
- Vérification et étoiles.
- Interface adaptée aux petits écrans.

## Lancer l'application
Ouvrir `index.html` dans un navigateur.

## Publier avec GitHub Pages
1. Créer un dépôt GitHub (par exemple `mon-petit-coach-maths`).
2. Ajouter les fichiers `index.html`, `style.css` et `app.js`.
3. Dans le dépôt, ouvrir **Settings > Pages**.
4. Choisir **Deploy from a branch**, puis `main` et `/ (root)`.
5. Enregistrer. GitHub Pages donnera une adresse web.

## Important — prototype pédagogique
Cette version est un premier prototype. Les exercices et la validation sont volontairement simples. Les retenues et emprunts sont saisis dans des cases dédiées, mais la prochaine amélioration devra guider l'enfant colonne par colonne et montrer visuellement les chiffres barrés/remplacés, notamment pour la soustraction avec emprunt.
